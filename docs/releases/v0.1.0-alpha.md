# AgentMargin v0.1.0-alpha — Release Notes

**Status:** experimental open-source source preview, **not production-ready**.

## What's included

- TypeScript cost engine with exact USD microdollar arithmetic.
- Historical model-pricing support for input, output and cached tokens.
- Reported / estimated / unknown inference cost states.
- Customer/workspace-scoped margin computation, where incomplete costs suppress final margin.
- PostgreSQL schema, authenticated API for usage/revenue ingestion and local analytics.
- Idempotent retries, tenant-scoped filtering and concurrency controls.
- Source-first TypeScript SDK and manual OpenAI Responses / Chat Completions usage helpers.
- Local browser analytics preview.
- CI with Node.js typecheck/tests, PostgreSQL concurrency, secret scanning, dependency audit and Chromium smoke testing using mocked API responses.

## What this release is not

- Not an npm-published SDK or automatic OpenAI instrumentation.
- Not a hosted service or production deployment guide.
- No built-in current provider price catalog, Stripe import or automated revenue sync.
- No independent penetration test, database RLS or public TLS gateway.
- No completed real-server/browser end-to-end security verification for an internet-facing deployment.

## Upgrade and start

There is no prior public release to upgrade from. See [Quickstart](../QUICKSTART.md) for the example engine and optional local PostgreSQL API.

## Known limitations

- Pricing must be trustworthy and manually supplied or reported; costs can be unknown.
- USD contribution excludes hosting, payment fees, support and other non-inference spend.
- Dashboard query range and response count are limited; truncated results are flagged.
- Rate limiting operates per process and should not be treated as public ingress protection.
- Do not use real customer data in an unreviewed environment.
