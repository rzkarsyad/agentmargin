# AgentMargin v0.3.0-alpha

> **Experimental open-source alpha, source-first and localhost-only. Not production-certified.**
>
> Do not expose the API/dashboard to the public internet or ingest real customer data without an independent deployment and security review.

This release advances AgentMargin from its v0.2 local accounting demo to **workspace-specific, auditable AI model pricing** and a redesigned **compact dark analytics workspace**, while preserving the existing source-first SDK and customer-level inference contribution calculations.

## Highlights

### 1. Auditable model prices for each workspace

- Authenticated `GET /v1/prices` and `POST /v1/prices`; the server determines the workspace from the bearer key, not client input.
- Exact nonnegative USD microdollar rates per million input, output, and optional cached-input tokens; the dashboard accepts familiar USD prices and converts without floating-point accounting.
- Explicit UTC effective-from and optional effective-to timestamps, source/verification notes, server-generated price version IDs, creation timestamps, and creator-key digests (not raw keys).
- Append-only PostgreSQL history (updates and deletes blocked) and workspace-bound foreign keys for usage events referencing a price version.
- New prices are used for **subsequent ingestion** at matching event timestamps. Already-persisted inference costs do **not** change when a price is added or superseded.
- Missing prices, including missing cached-input rates when needed, mean **unknown cost**, never an implicit $0.
- Legacy global price versions remain as read-only fallback for earlier timestamps; validate any rates before relying on them.

See [workspace pricing semantics and limitations](../PRICING.md).

### 2. Compact dark analytics dashboard

- React 19/Vite replacing the inline HTML preview when the frontend is built.
- Genuine free MIT-licensed [Arc UI](https://uiarc.dev/) source components for controls; upstream license is included in `apps/web/ARC_LICENSE.txt`. The dashboard's neutral dark layout is original AgentMargin code, informed by developer SaaS dashboard references.
- Functional workspace access, period selection, customer search/status filters, revenue and **known** AI-cost comparison, coverage summary, loss-making customer signals, and unknown-cost model diagnostics.
- Model Pricing view to create workspace-specific price versions and inspect a bounded version history.
- No fabricated time series, growth deltas, pricing amounts, or phantom actions. Unknown customer costs are marked **unverified** and partial.
- Responsive desktop/mobile, accessible labels and keyboard controls, and reduced-motion styles.

### 3. Verification

GitHub Actions exercises:
- `npm ci`, Vite build, TypeScript typecheck, source SDK/core/API tests.
- PostgreSQL 16 tenant isolation, ingestion idempotency, immutable pricing history and effective-date behavior.
- Dependency audit and heuristic source secret scan.
- Real Chromium desktop/mobile tests for the dashboard, pricing form and validation, including a live synthetic **Docker PostgreSQL → local API → SDK → analytics → browser** flow.

The source release is validated against **disposable, synthetic data**; a passing CI run does not establish production security.

## Quickstart

Requirements: Node.js **22.18+** (24 recommended), npm, OrbStack or Docker with Compose, and ports 55432/8787 available.

```bash
git clone https://github.com/rzkarsyad/agentmargin.git
cd agentmargin
npm ci
npm run demo
```

The command builds the React dashboard, boots localhost-only PostgreSQL, migrates the schema, seeds three fictional customers and prints a newly generated **AgentMargin workspace API key**. Open `http://127.0.0.1:8787/dashboard` and enter the key. Choose a period including the current UTC date.

The optional synthetic OpenAI-shaped event/revenue example is documented in [the demo guide](../DEMO.md). **No actual OpenAI credentials or network calls are required** for the demo.

Use Ctrl+C to stop the API and `npm run demo:stop` to stop the demo container without deleting its database volume. The destructive `npm run demo:reset` requires explicit confirmation; read the demo guide before resetting.

### Migrating an existing v0.2 development database

**Only for a disposable development database previously migrated through 003:**

```bash
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f db/004_workspace_pricing.sql
npm ci
npm run build:web
```

Migration 004 adds workspace price version records and a new optional price link on usage events. Existing records remain intact. No automatic down-migration or production upgrade procedure is shipped. Use the one-command demo for the safest synthetic evaluation path.

## Known limitations and safety

- Local-only experimental alpha. Not suitable for unreviewed public deployments or actual customer financial data.
- AI contribution here means **revenue minus tracked inference cost**, not gross margin or full net profit; other costs and provider billing reconciliation are not included.
- No official provider pricing catalog, automatic instrumentation, stable npm SDK release, or hosted service.
- Price versions are append-only, but **any valid workspace key** can add pricing versions; this is not a multi-user RBAC or approval system.
- No PostgreSQL RLS, audited TLS ingress, distributed rate limiting, production backup/restore, privacy lifecycle, or independent penetration test.
- Dashboard analytics and price history are bounded; truncation is surfaced, and displayed results must not be confused with complete organization totals.
